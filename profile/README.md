# Vicunav

Web studio building trust-centered digital presence and custom systems for local businesses.

We design and build WordPress (Gutenberg/FSE) websites and spec-driven systems — booking, ordering, and management tools — for service-based businesses.

🌐 [vicunav.com](https://vicunav.com)

## Repos

- **vicunav-gutenberg** — Our own site, migrated from Elementor to a native Gutenberg block theme
- **vicunav-restaurante** — Restaurant reference project: block theme, ordering plugin and demo content
- **vicunav-hub** — Architecture decisions and current state of the projects
- **vicunav-standards** — Shared engineering standards
- **vicunav-repo-template** — Starter template for new repositories

Built with spec-driven development, documented decisions (ADRs), and real QA — not just working code.
